# mp3clip — 動画から MP3 を切り出す

動画を読み込み、範囲・音量を指定して MP3 にする。ジャケット画像は動画のフレームから選ぶ。
外部依存なし（Node 標準ライブラリ + ffmpeg）。ポート **5190**。hub 配下では `/mp3clip/`。

## 使い方

1. 動画をドロップ（またはクリックして選択）。プレビューは手元のファイルで即座に始まり、
   サーバへのアップロードは裏で進む
2. 再生・シークして **I**（開始）/ **O**（終了）で範囲を決める。**P** で範囲だけ再生
3. 音量は2モード。どちらも再生中の音にそのまま反映される
   - **目標の音量（LUFS）**：絶対値。-30〜-6 LUFS で指定（既定 -14）。範囲を決めると自動でその範囲の
     音量を測り、「この範囲: -21.8 LUFS → -14.0 LUFS（+7.8 dB）」のように出す
   - **元の音量から増減（dB）**：±20 dB。0 dB は元の動画のまま
4. 気に入ったフレームで **C**（このフレームをジャケットに）。正方形の中央切り抜きは既定 ON
5. タイトル・アーティスト・アルバム・音質（128〜320 kbps）を入れて「MP3 を作る」

←→ で 1 秒、Shift+←→ で 0.1 秒移動。アーティスト・アルバム・音質などは次回も残る（localStorage）。

## 仕組み

| API | |
|---|---|
| `PUT api/upload?name=` | 動画を生のボディで受けて `work/` に置き、ffprobe で長さ等を返す |
| `GET api/measure?id&start&end` | 範囲のラウドネス（LUFS・true peak）。範囲ごとにキャッシュ |
| `GET api/frame?id&t&w&square` | 指定時刻のフレーム JPEG（ブラウザで再生できない形式のとき用） |
| `POST api/export` | 変換ジョブを開始。即座に job id を返す |
| `GET api/job?id` | 進捗（ffmpeg の `-progress` から） |
| `GET api/download?id` | 出来た MP3（`Content-Disposition: attachment`、日本語ファイル名可） |

- **ジャケットはブラウザが表示していたフレームそのもの**を canvas で JPEG にして送る（長辺 1200）。
  ffmpeg の `-ss t` は「t 以降の最初のフレーム」を取るので、サーバで切り出すと表示より1コマ後になるため。
  ブラウザで再生できない形式（avi・一部の mkv など）のときだけ、サーバの ffmpeg でフレームを取る
  （このときプレビューはコマ送り画像になり、音は聞けない）。
- **目標音量は loudnorm の2パス**（`api/measure` が1パス目、出力時に `measured_*` と `linear=true` を渡す）。
  一律に上げ下げするだけなので音質は変わらない。上げるとピークが -1 dBTP を超える場合だけ、ffmpeg が
  動的処理（軽い圧縮）に切り替える。このとき目標との差が大きいと届かない（ピンクノイズで -6 を狙うと -14.7 止まり）
  ので、出力後に MP3 を測り直して実際の LUFS を画面に出し、1 LU 以上足りなければ警告する。
- ffmpeg 4.4 は `measured_LRA=0` を「未指定」とみなして動的処理に落ちる（一定音量の音で起きる）。0.1 を下限にしてある。
- 変換をジョブ＋ポーリングにしているのは、hub のプロキシタイムアウト（120 秒）に掛からないようにするため。
- ID3v2.3 で書く（Windows のエクスプローラーがジャケットを表示できるのは v2.3）。元動画のタグは引き継がない。
- `work/` のアップロードと出力は 12 時間で自動削除（起動時と1時間ごと）。

ffmpeg は `C:\Program Files\ffmpeg-4.4-full_build\bin\` を優先し、無ければ PATH。
環境変数 `FFMPEG` / `FFPROBE` で上書きできる。
